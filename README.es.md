¿Para qué sirve?

LAN Chat es un chat sencillo para conversar con amigos y compañeros directamente entre computadoras, enviando mensajes e imágenes sin crear cuenta y sin un servidor que guarde tus conversaciones. Nació como un proyecto de estudio de redes y JavaScript, con un aspecto inspirado en Discord.
¿Cómo funciona?

Cada persona recibe un ID. Cuando te conectas al ID de alguien, tu navegador abre una conexión directa (WebRTC) con el suyo. Los mensajes y las imágenes van directo de uno a otro. Un servidor público solo ayuda a que ambos se encuentren al comienzo. El historial se guarda en tu propio navegador.
Paso a paso

    Copia tu ID en la parte superior de la página y envíaselo a tu amigo (por cualquier aplicación).
    Pídele su ID y haz clic en "+ Conectar por ID".
    Pega el ID, ponle un apodo (opcional) y confirma.
    Cuando el punto del contacto se ponga verde, está en línea. Elige el contacto y conversa.
    Usa el clip 📎 para enviar imágenes. Haz clic derecho en un contacto para eliminarlo.

Conviene saber

    Las dos personas necesitan tener la página abierta para intercambiar mensajes.
    No hay descubrimiento automático de contactos. El intercambio de IDs ocupa ese lugar.
    El historial se guarda solo en este navegador. Borrar los datos del sitio elimina todo.
    En redes muy restrictivas la conexión puede fallar.

Privacidad

Los mensajes no pasan por un servidor, pero el servidor de presentación puede ver los IDs y las direcciones de red de quien se conecta. No compartas tu ID con personas que no conoces: quien tenga tu ID puede pedir conversar (siempre puedes rechazar).
